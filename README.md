# Bella Notte Café — Cozy Coffee Story

Симулятор итальяно-американской кофейни на углу (английский и русский): короткие смены, 18 напитков от ристретто и доппио до аффогато и марокино, настоящее оборудование бариста с живой анимацией приготовления (холдер льёт эспрессо, питчер взбивает и наливает молоко, чайник, помпы сиропов, лёд), комбо, улучшения, постоянные гости района с историями, ежедневные задания и lo-fi музыка. Всё рисуется и звучит кодом — без внешних файлов и библиотек.

Играть онлайн: https://dolcefarcodiente.github.io/baristasimulator/

## Как запустить

На компьютере: открой `index.html` двойным кликом.

Чтобы работали офлайн-режим и установка на телефон, игру нужно открыть через сервер:

```bash
python3 -m http.server 8137 --directory "Coffee Shop"
```

и зайти на http://localhost:8137.

## Управление

- Мышь или палец: нажимай ингредиенты, потом на гостя, чтобы отдать напиток. Облачко «Как обычно!» можно нажать, чтобы подсмотреть заказ (без бонуса).
- Клавиатура: `Q W E R T Y U I O P A S D F G H` — кнопки оборудования (подписаны на кнопках), `Z X C` — чашки, `1–4` — отдать гостю, `Backspace` — вылить, `Esc` — пауза.
- Язык переключается кнопкой RU/EN в меню или на паузе.

## На телефон и в App Store

- **Как приложение с сайта:** открой ссылку на телефоне и выбери «На экран "Домой"».
- **Приложение для iOS (Capacitor):** проект лежит в `ios/`. Нужны Xcode и Node.

```bash
npm install
```

```bash
npm run ios
```

Команда собирает веб-часть в `dist/`, копирует её в iOS-проект и открывает его в Xcode. Дальше выбираешь симулятор или свой iPhone и нажимаешь ▶. Для публикации в App Store нужен аккаунт Apple Developer: в Xcode укажи свою команду в Signing & Capabilities, затем Product → Archive.

После любых правок в игре повторяй `npm run ios`, чтобы приложение подхватило новые файлы.

## Графика

Фон кофейни, гости, кот и предметы на стойке — пиксель-арт в `img/` (сгенерирован по текстовым описаниям в стиле 16-битных визуальных новелл). Исходники с зелёным хромакей-фоном обрабатывает `scripts/keyout.swift`: вырезает зелёный, обрезает по содержимому и уменьшает:

```bash
swiftc -O -o /tmp/keyout scripts/keyout.swift && /tmp/keyout source.png img/name.png 340
```

Стёкла окна на фоне прозрачные — туда игра рисует небо, дождь и город, которые за смену уходят от заката в глубокую ночь (18:00 → 02:00). Раскладка фона (где стойка, доска, лампы) описана долями в `js/sprites.js`.

Сцена и чашки рисуются в маленький буфер и растягиваются без сглаживания, поэтому всё попадает в одну пиксельную сетку; облачка заказов, меню на доске и надписи рисуются поверх чётко. Шрифт — Pixelify Sans (лицензия OFL, `fonts/`).

## Файлы

- `js/data.js` — рецепты, улучшения, гости, баланс
- `js/shift.js` — логика смены
- `js/sprites.js` — загрузка нарисованных ассетов и раскладка фона
- `js/art.js` — сцена: ночь и дождь за окном, свет, гости, кот, эффекты
- `js/talk.js` — реплики гостей в рамке диалога
- `js/bar.js` — барная стойка: чашки и анимация приготовления
- `js/ui.js` — интерфейс и экраны
- `js/progress.js` — задания, серия, достижения, ёжик
- `js/i18n.js` — переводы интерфейса
- `js/audio.js` — звуки и музыка
- `js/save.js` — сохранение
